🌱 Firebase 연결 설정

실시간 모둠 공유를 위해 Firebase를 연결해 주세요.
아래 안내를 따라 무료로 설정할 수 있어요.

1단계. console.firebase.google.com 접속 → 새 프로젝트 만들기
2단계. 프로젝트 → Realtime Database → 데이터베이스 만들기 (테스트 모드 선택)
3단계. 프로젝트 설정 → 웹 앱 추가 → databaseURL 값 복사
올바른 databaseURL을 입력해 주세요.
